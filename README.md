# Desk Clock

インストール不要で動作する、軽量かつ洗練されたオリジナルのデスクトップ時計です。
Windows ネイティブ（PowerShell + WPF）で動作します。

---

## 🚀 使い方

- **起動**: `start_clock.vbs` をダブルクリックします。
- **終了**: 時計を右クリック →「終了」

黒いコンソール画面が出ない **完全サイレント起動** です。インストールも管理者権限も不要なので、会社の PC でもそのまま動作します。

---

## 🌟 特徴

- **インストール不要・管理者権限不要**: ファイル単体で即座に動作します
- **超軽量 & 低負荷**: 無駄な依存関係がなく、CPU・メモリへの負荷を最小限に抑えています
- **ミニマルなデザイン**:
  - 数字表記を省いたシンプルでモダンな文字盤
  - 細さを揃えたスマートな時針・分針
  - 完全な枠なし・タイトルバーゼロ。時計以外の余計な UI は一切表示されません
- **背後のアプリを塞がない**: 操作を受け付けるのは文字盤・文字の**中央 45%** だけで、それ以外の領域のクリックは背後のウィンドウへそのまま抜けます
- **クリックすり抜けモード (`Ctrl + Shift + X`)**: 時計の裏側にあるウィンドウや Excel を直接クリック・操作可能
- **最前面固定 (`Ctrl + Shift + T`)**: 他のウィンドウの手前に常に表示
- **スマート透過（マウス連動）**: 普段は薄く背景に馴染み、マウスを近づけた時だけクッキリ表示
- **Windows 起動時に自動起動**: 設定メニューからワンクリックで登録／解除
- **表示モード切替**: アナログ時計 ⇄ デジタル時計をいつでも切り替え可能（既定はアナログ）
- **アナログとデジタルで同一の配色**: デジタルの文字色はアナログの針と同じ色を共有し、テーマを変えてもずれません
- **アナログとデジタルで同一の操作感**: ホイール操作・表示倍率はモードによらず同じ刻みで動作し、倍率はモードを跨いで引き継がれます
- **秒針表示 ON / OFF**: デフォルト OFF（右クリックでいつでも ON 可能）
- **超省電力タイマー同期**: 秒針 OFF 時は更新を次の「00 秒」に同期させて 1 分間隔まで自動的に落とし、CPU 稼働時間をほぼゼロに抑えます（秒針 ON で即座に 1 秒間隔へ復帰）
- **日付・曜日表示**: デジタル表示時に `8月26日 (水)` を控えめな低コントラストで表示（デフォルト OFF）
- **背景によらず読める文字**: デジタル表示の文字には文字色と逆の明度の縁取りが入り、壁紙やアプリの色を選びません。それでも読みにくい場所では「背景を敷く」で背景板を出せます
- **ワンタッチスナップ配置**: 画面の四隅・上中・中央へ、作業領域（タスクバーを除いた範囲）基準で瞬時に整列
- **マルチモニタ対応**: 時計が乗っているモニタを基準に配置し、解像度変更やモニタ着脱にも追従します
- **針の太さ・長さを調整**: 時針・分針・秒針それぞれの太さ（px）と長さ（%）を微調整可能（時針が分針以上に長くならないよう自動で拘束されます）
- **カラーテーマ**: ダーク / ライト / ブルー の 3 種
- **透明度調整**: 15% 〜 90%（マウスホイールで 5% 刻みの微調整も可能）
- **既定サイズ**: 起動時のアナログ時計は一辺 220px（表示倍率 100%）。`Ctrl + ホイール` で 40%〜360%（88px〜792px）に調整可能
- **初回起動時の既定配置**: アナログ時計を画面の右上（作業領域基準・余白 16px）に配置
- **設定の永続化**: テーマや針の設定、サイズ、位置は自動で保存されます

## ⌨️ 操作方法

いずれの操作も、時計の**中央 45%** の範囲で受け付けます。

| 操作 | 説明 |
|---|---|
| **右クリック** | 設定メニューを開く（テーマ、透明度、針の設定、機能の ON/OFF、配置スナップ） |
| **ダブルクリック** | アナログ ⇄ デジタル 表示モードを切り替え |
| **ドラッグ** | 時計を画面内の好きな位置へ移動 |
| **マウスホイール** | 透明度を 5% 刻み（15%〜90%）で直感微調整 |
| **`Ctrl` + マウスホイール** | 表示倍率を 5% 刻み（40%〜360%）で拡大・縮小。両モードで同じ操作・同じ刻みで、倍率はモードを跨いで引き継がれます |
| **`Ctrl + Shift + T`** | 最前面固定（Always on Top）の ON / OFF を切り替え |
| **`Ctrl + Shift + X`** | クリックすり抜けモードの ON / OFF を切り替え |

> **注意**: クリックすり抜けを ON にすると、時計はマウス操作を一切受け付けなくなります。
> 解除するにはタスクバーから時計を選択してフォーカスを当ててから `Ctrl + Shift + X` を押してください。

### 右クリックメニューから使える機能

- **最前面に固定**: 最前面表示の ON / OFF（ショートカット: `Ctrl + Shift + T`）
- **秒針を表示**: 秒針の ON / OFF（デフォルト OFF、OFF 時は超省電力モードに自動適応）
- **スマート透過**: 普段は薄く表示し、マウスを近づけた時だけクッキリ表示
- **クリックすり抜け**: 時計の裏側のウィンドウをそのままクリック・操作可能にする
- **日付・曜日を表示**: デジタルモード時に日付と曜日を控えめに表示
- **背景を敷く**: デジタルモード時に文字盤と同じ色の背景板を表示（デフォルト OFF）。白いウィンドウの上など、縁取りだけでは読みにくい場所に置くとき用
- **配置スナップ**: 画面の四隅（左上・右上・左下・右下）＋上中・中央の 6 か所へワンクリックで整列
- **Windows 起動時に自動起動**: スタートアップに自動登録／解除
- **針の設定 / デジタル文字サイズ / カラーテーマ / 透明度**: 各種プリセットから選択
- **設定リセット**: すべての設定を初期状態に戻す

## 📁 ファイル構成

```
DESK_CLOCK/
├── start_clock.vbs       # 【起動用】サイレント起動スクリプト
├── desk_clock.ps1        # 時計本体 (PowerShell + WPF)
└── README.md             # 本説明ファイル
```

設定は `%APPDATA%\DeskClock\settings.json` に保存されます。
初期状態に戻したい場合は、時計を終了してからこのファイルを削除してください。
