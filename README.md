# Desk Clock (YClock風デスクトップ時計)

インストール不要で動作する、軽量かつ洗練されたYClock風のデスクトップ時計です。  
**HTML版（ブラウザ起動）** と **PowerShell + WPF版（Windowsネイティブ起動）** の2種類を用意しています。

---

## 🌟 特徴

- **インストール不要・管理者権限不要**: ファイル単体で即座に動作します（会社のPCでも利用可能）。
- **超軽量 & 低負荷**: 無駄な依存関係がなく、CPU・メモリへの負荷を最小限に抑えています。
- **ミニマルなデザイン**:
  - 数字表記を省いたシンプルでモダンな文字盤
  - 細さを揃えたスマートな時針・分針
  - 背景に溶け込む黒背景・落ち着いた低コントラスト設計
- **針の太さ・長さを自由に調整**: 時針・分針それぞれの太さ（px）と長さ（%）を設定メニューから微調整可能
- **デジタル文字サイズの変更**: デジタル表示時の文字サイズ（フォントサイズ）を自由に変更可能
- **表示モード切替**: アナログ時計 ⇄ デジタル時計をいつでも切り替え可能
- **秒針表示 ON / OFF**: 集中作業時に秒針を非表示にできます
- **カラーテーマ**: ダーク / ライト / ブルー の3種
- **透明度調整**: 30% 〜 100%
- **レスポンシブ & ドラッグ移動**: ウィンドウサイズに自動追従、好きな位置に配置可能
- **設定の永続化**: テーマや針の設定、サイズは自動で保存されます

---

## 🚀 使い方

### 1. HTML版 (`desk_clock.html`)
ブラウザで動作するクロスプラットフォーム版です。

- **起動**: `desk_clock.html` をダブルクリックしてブラウザで開きます。
- **モード切替**: 時計を **ダブルクリック** すると「アナログ ⇄ デジタル」が切り替わります。
- **設定メニュー**: 時計上で **右クリック** すると設定メニューが表示されます。
  - 表示モード（アナログ / デジタル）
  - 秒針の表示／非表示
  - **針の設定**（時針 太さ/長さ、分針 太さ/長さ）※アナログ時
  - **デジタル設定**（文字サイズ）※デジタル時
  - カラーテーマ（ダーク / ライト / ブルー）
  - 透明度スライダー
- **位置移動**: 時計をドラッグして画面内の好きな場所に配置できます。

> **💡 Always on Top（最前面表示）の小ワザ:**  
> Windows PowerToys をお使いの場合、`Win + Ctrl + T` でブラウザを最前面固定できます。

---

### 2. PowerShell + WPF版 (`desk_clock.ps1` / `start_clock.bat`)
Windows デスクトップ専用のネイティブ版です。

- **起動方法（いずれか1つ）**:
  - `start_clock.bat` をダブルクリック
  - `start_clock.vbs` をダブルクリック（黒い画面が一瞬も出ない完全サイレント起動）
- **デバッグ起動**: もし起動しない場合は `debug_clock.bat` を実行するとエラーメッセージを確認できます。
- **特徴**:
  - 枠なし・完全透過ウィンドウ
  - ネイティブで **常に最前面（Always on Top）** 表示
  - 時計を **ダブルクリック** でアナログ ⇄ デジタル切替
  - ウィンドウ右下をドラッグしてリサイズ可能
  - 時計をドラッグしてデスクトップ上の任意の位置へ配置可能
- **設定メニュー**: 時計上で **右クリック** して設定変更や終了が行えます。

## 📁 ファイル構成

```
DESK_CLOCK/
├── desk_clock.html   # HTML版 単一ファイル
├── desk_clock.ps1    # PowerShell + WPF版 スクリプト
├── start_clock.bat   # 起動用バッチファイル (CMD)
├── start_clock.vbs   # 起動用VBScript (黒画面なし)
├── debug_clock.bat   # エラー確認用バッチファイル
└── README.md         # 本説明ファイル
```
