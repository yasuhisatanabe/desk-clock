# Desk Clock

インストール不要で動作する、軽量かつ洗練されたオリジナルのデスクトップ時計です。  
**HTML版（ブラウザ・アプリモード起動）** と **PowerShell + WPF版（Windowsネイティブ起動）** を用意しています。

---

## 🌟 特徴

- **インストール不要・管理者権限不要**: ファイル単体で即座に動作します（会社のPCでも利用可能）。
- **超軽量 & 低負荷**: 無駄な依存関係がなく、CPU・メモリへの負荷を最小限に抑えています。
- **ミニマルなデザイン**:
  - 数字表記を省いたシンプルでモダンな文字盤
  - 細さを揃えたスマートな時針・分針
  - 背景に溶け込む黒背景・落ち着いた低コントラスト設計
- **スマート透過（マウス連動）**: 普段は薄く背景に馴染み、マウスを近づけた時だけクッキリ 100% 表示
- **クリックすり抜けモード (`Ctrl + Shift + X`)**: 時計の裏側にあるウィンドウやExcelを直接クリック・操作可能
- **Windows起動時に自動起動**: 設定メニューからワンクリックで毎朝の自動立ち上げを登録/解除可能
- **針の太さ・長さを調整**: 時針・分針・秒針それぞれの太さ（px）と長さ（%）を設定メニューから微調整可能（時針が分針以上に長くならないよう自動で拘束されます）
- **デジタル文字サイズの変更**: デジタル表示時の文字サイズ（フォントサイズ）を自由に変更可能
- **表示モード切替**: アナログ時計 ⇄ デジタル時計をいつでも切り替え可能（既定はアナログ）
- **アナログとデジタルで同一の配色**: デジタルの文字色はアナログの針と同じ色を共有し、テーマを変えてもずれません
- **アナログとデジタルで同一の操作感**: ホイール操作・表示倍率はモードによらず同じ刻みで動作し、倍率はモードを跨いで引き継がれます
- **秒針表示 ON / OFF**: デフォルトOFF（右クリックでいつでもON可能）
- **超省電力タイマー同期**: 秒針OFF時は更新を次の「00秒」に同期させて 1 分間隔まで自動的に落とし、CPU稼働時間をほぼゼロに抑えます（秒針ONで即座に 1 秒間隔へ復帰）
- **最前面固定 (`Ctrl + Shift + T`)**: 他のウィンドウの手前に常に表示 *(PS1版で有効)*
- **ワンタッチスナップ配置**: 画面の四隅・上中・中央へ、作業領域（タスクバーを除いた範囲）基準で瞬時に整列
- **日付・曜日表示**: デジタル表示時に `8月26日 (水)` を控えめな低コントラストで表示（デフォルトOFF）
- **カラーテーマ**: ダーク / ライト / ブルー の3種
- **透明度調整**: 15% 〜 90%（マウスホイールで 5% 刻みの微調整も可能）
- **完全な枠なし・タイトルバーゼロ**: 時計以外の余計なUIは一切表示されません
- **背後のアプリを塞がない** *(PS1版)*: 操作を受け付けるのは文字盤・文字の中央 60% だけで、
  それ以外の領域のクリックは背後のウィンドウへそのまま抜けます
- **控えめな既定サイズ** *(PS1版)*: 起動時のアナログ時計は一辺 110px。`Ctrl + ホイール` で 55%〜360% に調整可能
- **レスポンシブ & ドラッグ移動**: ウィンドウサイズに自動追従、好きな位置に配置可能（画面外に取り残された場合は自動で画面内へ復帰）
- **初回起動時の既定配置**: アナログ時計を画面の右上（作業領域基準・余白16px）に配置
- **設定の永続化**: テーマや針の設定、サイズ、位置は自動で保存されます

## 🚀 使い方

### 1. HTML版 (`desk_clock.html`)
ブラウザで動作するクロスプラットフォーム版です。

- **起動**: `desk_clock.html` をダブルクリックしてブラウザで開きます。
- **注意**: ブラウザの制約により、**最前面固定はブラウザ自身では強制できません**。
  メニューの「最前面に固定」は設定を保持するだけなので、実際に最前面へ固定したい場合は
  Windows PowerToys の `Win + Ctrl + T` を併用するか、PS1版（`start_clock.vbs`）をご利用ください。

---

### 2. Windows デスクトップアプリ起動 (`start_clock.vbs`)
Windows環境で最もおすすめの起動方法です。

- **起動**: `start_clock.vbs` をダブルクリックします。
- **特徴**:
  - 黒いコンソール画面が出ない **完全サイレント起動**
  - アドレスバーやタブのない、洗練された **専用デスクトップ時計ウィンドウ** として起動
  - インストール不要・管理者権限不要（会社のPCでも100%動作）
  - 時計を **ダブルクリック** で「アナログ ⇄ デジタル」切替
  - 時計上で **右クリック** して針の太さ/長さ、文字サイズ、テーマ、透明度を自由に設定
  - 時計をドラッグして画面内の好きな位置へ配置可能、または四隅へ **ワンタッチスナップ配置**
  - 時計の上で **マウスホイール** を回して透明度を、`Ctrl + ホイール` でサイズを直感的に微調整（両モード共通の操作）
  - `Ctrl + Shift + T` でいつでも **最前面固定（Always on Top）** を切替
  - 秒針OFF時は自動で **1分間隔更新（超省電力）** に同期

## ⌨️ 操作方法

| 操作 | 説明 |
|---|---|
| **右クリック** | 設定メニューを開く（テーマ、透明度、針の設定、機能の ON/OFF、配置スナップ） |
| **ダブルクリック** | アナログ ⇄ デジタル 表示モードを切り替え |
| **ドラッグ** | 時計を画面内の好きな位置へ移動（時計の周囲の余白も掴めます） |
| **マウスホイール** | 時計上でホイール回転して透明度を 5% 刻み（15%〜90%）で直感微調整 |
| **`Ctrl` + マウスホイール** | 表示倍率を 5% 刻み（40〜360%）で拡大・縮小。アナログ・デジタルで同じ操作・同じ刻み |
| **`Ctrl + Shift + T`** | 最前面固定（Always on Top）の ON / OFF を切り替え |
| **`Ctrl + Shift + X`** | クリックすり抜けモードの ON / OFF を切り替え |

### 右クリックメニューから使える機能

- **最前面に固定**: 最前面表示の ON / OFF（ショートカット: `Ctrl + Shift + T`）
- **秒針を表示**: 秒針の ON / OFF（デフォルト OFF、OFF時は超省電力モードに自動適応）
- **スマート透過**: 普段は薄く表示し、マウスを近づけた時だけクッキリ表示
- **クリックすり抜け**: 時計の裏側のウィンドウをそのままクリック・操作可能にする
- **日付・曜日を表示**: デジタルモード時に日付と曜日を控えめに表示
- **配置スナップ**: 画面の四隅（左上・右上・左下・右下）＋上中・中央の 6 か所へワンクリックで整列
- **Windows起動時に自動起動** *(PS1版のみ)*: スタートアップに自動登録/解除
